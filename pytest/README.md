## Выполнение задания

1. **Длина строки:** `string_length(text)` из `main.py` возвращает число символов. Тесты проверяют пустую строку, только пробелы и многострочную строку (`\n` учитывается).
2. **Сохранение строки:** `save_string_to_file(text, file_path)` записывает текст в файл в кодировке UTF-8. Тесты проверяют обычный/многострочный текст, пустой файл и перезапись.
3. **Фикстура SQLite:** `db_connection` в `conftest.py` создаёт отдельную временную базу данных для каждого теста (`scope="function"`), создаёт таблицу `messages`, передаёт подключение через `yield`. После теста срабатывает код в `finally`: удаляет записи из таблицы, закрывает соединение и удаляет временный файл БД. Тесты проверяют пустую БД, вставку/чтение данных и несколько записей.

## Запуск в Debian / VS Code

Распакуйте файлы в `~/Рабочий стол/kt2/` (не в дополнительную вложенную папку).

Если окружение `.venv` уже создано и pytest установлен:

```bash
cd "$HOME/Рабочий стол/kt2"
source .venv/bin/activate
python -m pytest -v
```

Если окружение ещё не создано:

```bash
cd "$HOME/Рабочий стол/kt2"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -v
```

Ожидаемый результат: **9 passed**, при условии штатного выполнения. 

### Как проверяется очистка

Фикстура `db_connection` — **function-scoped**. Каждый из трёх тестов получает новую SQLite-БД; в тестах есть проверка, что в начале работы таблица пуста. После выполнения каждого теста блок `finally` удаляет записи, закрывает соединение и удаляет созданный файл SQLite. Очистка выполняется также при провале утверждения теста.
